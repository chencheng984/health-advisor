# 数据分级与去向

| 级别 | 内容 | 去向 |
| --- | --- | --- |
| L0 原始 | 导出 ZIP、XML、原始采样、ECG 波形、路线坐标 | 原始文件留在本地。导入时读取所需字段和附件，SQLite 保留分析需要的采样数据及附件摘要。 |
| L1 可识别 | 姓名、账号、手机号、设备序列号、原始路径 | 原始文件中的可识别字段留在本地。导入时舍弃身份字段，来源归为通用类型。旧缓存先备份，再迁移。 |
| L2 聚合 | 区间统计、覆盖、来源类型、睡眠分期与训练类型摘要 | `brief` 的 JSON 与 `report` 的 Markdown 可供复盘。按任务需要分享，进入云端会话的聚合信息可能随对话保存。 |
| L3 结论 | 观察、行动优先级、复核条件 | 随本轮复盘交付。跨会话保存以用户同意为前提，保留必要且可撤回的内容。 |

`brief` 与 `report` 的 `privacy` 标记输出级别、直接读取原始文件与否、身份字段披露状态及备注。
`--with-identifiers` 额外提供每个区间的来源数量，输出仍为 L2。未列入训练类型字典的类别合计到「其他运动」。

本地清理用 `purge --scope cache|memory|all`。默认预览清单与大小，显式添加 `--yes` 执行。
`cache` 涵盖所选 SQLite 缓存及附属文件、同目录的 `.run/` 和临时缓存。`memory` 涵盖同目录的 `memory.json` 与临时写入文件。
本地记忆仅存用户同意保留的要点。保存前核对是否夹带姓名、账号、地址、设备序列号或逐日数值。`brief` 带出当前目标、约束与最新复盘，Markdown 和工作台只带出上次的一句话结论和复核提示。要生成不含记忆的输出，使用 `--no-memory`。
