# 健康测量与设备记录

适用于心率、呼吸频率、血氧、体重、体脂、最大摄氧量或用户主动询问设备通知。

| 用户想了解 | 优先核对 |
| --- | --- |
| 心率变化 | `heart_rate` 是观测汇总，`resting_hr` 是设备提供的静息心率指标。用明确测量场景和来源解释。单点问题要区分原始观测与日聚合。 |
| 呼吸与血氧 | 查询 `respiratory_rate` 或 `oxygen_saturation`，列来源、单位、有效覆盖与可比性。症状按健康边界处理。设备读数用于描述观测。 |
| 体重与体脂 | 查询 `body_mass` 或 `body_fat`，用覆盖足以反映测量频率的窗口。优先核对使用同一设备与测量条件。百分比指标的绝对差值用百分点。 |
| 最大摄氧量 | 查询 `vo2_max`，说明采样覆盖和设备提供的估算口径。样本稀疏时列记录时间与当前值，运动表现还需相应训练数据。 |
| 设备通知、心电图、血压或其他附件 | `status` 中的计数与 `inventory_only` 只用于盘点。可准确转述用户提供的通知原文，具体测量或症状交给医疗专业人员评估。 |

给综合判断的内容限于这一主题对用户问题有帮助的观察、数据限制与一个核实办法。相关设备能力可查 [Apple 心脏健康通知](https://support.apple.com/zh-cn/120276) 和 [Apple 血氧测量说明](https://support.apple.com/en-tm/120358)。
